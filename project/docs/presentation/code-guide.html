Dijkstra(network, source) — переменные

ПеременнаяЧто это
nЧисло перекрёстков
distance[v]Лучшее известное время от source до v; в начале Unreachable
previous[v]Откуда пришли в v по кратчайшему пути; −1 — у источника и недостижимых

dist > distance[node]Устаревшая запись — пропуск (ленивое удаление)
candidateВремя до соседа через node; в long — без переполнения

ShortestPathTree — результат

  • DistanceTo(v) — кратчайшее время
  • CanReach(v) — достижим ли v
  • PathTo(v) — путь: идёт по previous от v назад к источнику, затем разворачивает список

В PriorityQueue нет decrease-key — поэтому вершина кладётся повторно, а старые записи отбрасываются.

Planning/DpRoutePlanner.cs · состояние

mask, last и таблица finish

Битовая маска доставленных заказов

  • mask — какие заказы уже доставлены
  • last — заказ, доставленный последним: у него стоит курьер
  • next — заказ, который пробуем следующим

finish[mask * k + last]

Самая ранняя минута, когда курьер закончил заказ last, доставив ровно mask

previous[mask * k + last]

Какой заказ был перед last; FromDepot — если last первый. Тип sbyte — 1 байт

Таблица двумерная [mask][last], но хранится одним массивом: индекс = mask · k + last

Planning/DpRoutePlanner.cs · переход

Relax — один переход DP

ПеременнаяЧто это
fromPointОткуда едем — точка (0 или last + 1)
fromOrderОткуда едем — заказ, для previous
timeКогда освободились на прошлом месте
legВремя проезда до next
arrivalВремя прибытия к next
doneКонец передачи заказа next
indexЯчейка состояния (mask ∪ {next}, next)
int leg = travel.Minutes(fromPoint, next + 1);
long arrival = time + leg;
if (arrival > deadline[next]) return;  // дедлайн

long done = arrival + service[next];
if (done + back[next] > shift)   // отсечение:
    return;                        // не успеть назад

// добавили next в маску
int index = (mask | (1 << next)) * k + next;
if (done < finish[index])         // раньше?
{
    finish[index] = (int)done;
    previous[index] = fromOrder;
}

Planning/DpRoutePlanner.cs · ответ

Выбор лучшего состояния и восстановление пути

ПеременнаяЧто это
valueOfMask[mask]Ценность заказов маски: valueOfMask[mask & (mask−1)] + ценность младшего заказа
lowНомер младшего бита (TrailingZeroCount)
tfinish текущего состояния
returnMinuteВозврат на склад: t + back[last]
bestValue, bestReturnЛучшая ценность и возврат при ней; старт 0 и 0 — пустой маршрут
bestMask, bestLastГде достигнут лучший результат; −1 — пустой маршрут

Восстановление — с конца

for (mask = bestMask, last = bestLast;
     last != FromDepot;)
{
    sequence.Add(last);
    int prev = previous[mask * k + last];
    mask &= ~(1 << last);   // снять бит
    last = prev;
}
sequence.Reverse();

mask & (mask − 1) убирает младший установленный бит: 101 → 100

Как DP проходит ловушку шаг за шагом

Заказы: 0 = N (Киоск), 1 = F1, 2 = F2. Смена 75. Со склада: N — 5, F1 — 30, F2 — 35 мин

МаскаlastfinishКак получено
001 {N}N5склад → N
010 {F1}F130склад → F1
100 {F2}F235склад → F2
011 {N, F1}F140N(5) + 35; возврат 40 + 30 = 70 ≤ 75 ✓
011 {N, F1}N65F1(30) + 35; возврат 65 + 5 = 70 ✓
101 {N, F2}——оба порядка дают возврат 80 > 75 — отсечено
110 {F1, F2}F235F1(30) + 5; возврат 35 + 35 = 70 ✓
110 {F1, F2}F140F2(35) + 5; возврат 40 + 30 = 70 ✓
111 {все}——любой порядок даёт возврат > 75 — отсечено

Ценность: маска 011 → 6, маска 110 → 10. Ответ — {F1, F2}, возврат в 70 мин
